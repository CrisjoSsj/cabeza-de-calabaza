# Cabeza de Calabaza 🎃

Mini juego web basado en la tendencia de TikTok **Pumpkin Head Illusion** (octubre 2026):
toca la pantalla justo cuando la calabaza tape la cabeza del bailarín.

- 100 % estático (HTML + CSS + JS), sin dependencias ni backend.
- Mobile-first, controles táctiles, partidas de ~45 s.
- Récord guardado en `localStorage`, botón Reiniciar y Compartir (Web Share API con copia del enlace como respaldo).

## Jugar en local

```bash
python3 -m http.server 8765
# abre http://localhost:8765
```

Capturas en `capturas/`.
